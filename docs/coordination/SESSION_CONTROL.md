## Start protocol for live sessions

1. Read [root AGENTS](../../AGENTS.md) and [bootstrap](../PROJECT_BOOTSTRAP.md).
2. Choose assigned role file in [handoffs](../session-handoffs/README.md).
3. Check current main SHA and open PR/issue, claim an unowned issue with branch/paths; integrator prevents duplicate writers.
4. Use independently authorized tool access; do not infer all session credentials.
5. Complete and test one independently useful output; create a PR or verifiable restricted artifact.
6. Return explicit result/links via lane's GitHub issue or private Notion record; integrator reconciles.
7. Stop at money, external outreach, legal/clearance or uncertain effects and raise concise Chairman decision.
