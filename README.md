# AERLOR

**The art of a better stay.** An original hospitality-focused prelaunch website: editorial design, an interactive product study, and a property-inquiry experience.

## Status

Initial website implementation in progress. This repository is the source of truth for the AERLOR website. Product imagery represents design concepts, not production units. No product certification, inventory, pricing or sample availability is implied.

## Paper design

The existing Paper desktop adapter is connected but currently rejects writes because its approved tool catalog differs from the upstream catalog. No unrelated Paper document has been edited. Editable HTML design studies will be included for native import when the approved connection is restored and an AERLOR document is bound.

## Stack

Vite, TypeScript and an original procedural Three.js product scene; static SVG fallback. No analytics pixels. A verified inquiry endpoint is a separate commercial-launch gate; the default preview prepares a local downloadable brief and does not pretend to send messages.
